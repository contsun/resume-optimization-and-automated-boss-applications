## 首次沟通前的基本确认

- [ ] 已明确提醒本人在自己的电脑浏览器登录；本人已确认，不索要密码、验证码或 Cookie。
- [ ] 当前账号为本人；未共享登录态或验证码。
- [ ] 已确认这次使用的简历文件与版本，不默认优化或同步。
- [ ] 已分别询问在线/附件是否更新；本人选择：<只在线 / 只附件 / 两者 / 都不更新>。
- [ ] 本次岗位、城市、薪资口径、范围与最多沟通数量已确认；默认不发附件。
- [ ] 平台资料与参考简历仅版本不同或未知时只提示一次，用户可保留现状继续首次沟通，不要求一致。

## 仅选择更新或另行发附件时检查

以下项目按所选动作适用，不是只发首次招呼的必过清单。

- [ ] 仅对已选择更新的部分展示差异或目标文件，并取得具体修改确认；未选择部分保持不变。
- [ ] 必要联系信息和隐私范围由本人确认。
- [ ] 求职期望与当前目标岗位、城市、薪资单位一致。
- [ ] 公司、品牌、职位、年月、项目与教育经历真实一致。
- [ ] 职业概述可快速阅读，数字均有私有事实编号。
- [ ] 保存后读回核对；审核状态按当前页面单独记录。
- [ ] 附件文件名、正文版本、日期、分页和文字可检索性正确。
- [ ] 当前附件预览与预期一致，未将旧版或内部证据一起上传。
- [ ] 明确资料保存不等于首次沟通，首次沟通不等于附件送达。
- [ ] 不更新时保留现状；不因版本未核对或不同而阻断首次沟通，也不谎称已核验一致。
- [ ] 平台登录与简历更新不作为投递授权；本次范围、数量与发送动作另行确认。
